MIGRATION AND MODEL CLASS NAMES
Day 6
- Learned about the database migration folder and files, These allows you to creates tables in db and easily migrate it so other devs will not use sql query just 'php artisan migrate'.
- Learned about 'artisan migrate' which transfer only the new created table into existing table in db, 'artisan migrate:fresh' refresh and transfer all the created table including the defaults into your db. Use 'php artisan' to see all the commands
- Learned about Eloquent, it is a ORM(object relational mapper) where it automatically connect to your db, and instead of sql query you can use php systax to query specific table in your db
    - Learned some eloquent method like ::all(), ::find(//like id from wildcard)
- Learned that you classname located in 'app/Model/', when use Eloquent it will automatically connect to its corresponding table name in your db, so if you have User.php -> connect to user table
- Learned that if you have customize table name that is not part of the defaults tables and want to use it inside a class of default name of table such as; User, Job, you have to declare it as 'protected $table //your customize table name'

ELOQUENT RELATIONSHIP
Day 9
- Learned about eloquent relationships, this helps understand the relationships between tables using foreign keys
- learned about 'hasMany(//the class that has the data)', example a Post(model) has many Comments(model)
- learned about 'belongsTo(//the class where it belongs)', example Comments(model) belongs to a Post(model)
- Learned about first() method, where it will get the first data or row in db
- *Note create custom method that will contains those eloquent methods then when you will call it you dont have to use '()'. Example $job = App\Models\Job::first(), now you can use the method called employer you created that has belongsTo() through-> $job->employer->name
