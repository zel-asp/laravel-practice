LAZY LOADING
Day 11
- Learned about lazy loading. A concept of calling or querying a data only if you call it, example $post = App\Models\Post::find(1); // Only fetches the post
- Lazy loading can become heavy when loop, since it will query each loop round which create N+1
- The N+1 problem is a performance issue that happens when your code runs one query for the main data (1) and then one query for each related item (N).
- Learned about how to disable it through 'App\Providers' folder and under the boot method 'Model::preventLazyLoading();'
- If you want to use it, use eager loading of 'with(//the relationship method in that particular model)'
- Downloaded 'laravel-debugger', it helps you to see what's happening behind, you can see it directly on you local server

    - Seeders call the creation of thos data
